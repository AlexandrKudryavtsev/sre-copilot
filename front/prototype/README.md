# SRE Copilot

Локальный интерактивный frontend-прототип на React 19 и TypeScript. Интерфейс на английском языке. Стили: CSS + Tailwind; компоненты shadcn/Base UI; графики Recharts. Сборка и dev-server: Vite/Vinext.

## Запуск

Требуется Node.js 22.13+.

```bash
npm install
npm run dev
```

Откройте адрес, который напечатает dev-server (обычно http://localhost:3000).

```bash
npm run build
npm run typecheck
npm run lint
npm test
```

## Демонстрация

1. Dashboard (`#/`) показывает состояние Checkout API, четыре Golden Signals, диапазон графиков и активные инциденты.
2. `View all incidents` / пункт `Incidents` открывает таблицу (`#/incidents`), поиск и фильтры по статусу и severity.
3. Основной критический инцидент `INC-1042` выделен на Overview и первым показан в таблице активных инцидентов. Его карточка сразу открывается с готовыми AI-выводами, правилом, метриками и рекомендациями.
4. Вторичный `INC-1041` начинает в состоянии **Analyzing**: он уже существует, и его карточка доступна во время анализа. Таймер демонстрации стартует при первом входе в Incidents или Incident Details и завершается через 30 секунд, независимо от дальнейшей навигации. `Replay analysis` повторяет Queued (2,5 секунды) → Analyzing (30 секунд для INC-1041, 8,5 секунды для остальных) → Completed. Основной инцидент сохраняет завершённый анализ, пока его явно не перезапустят.
5. `Acknowledge`, `Resolve incident` и `Reopen incident` обновляют статус, таблицу и счетчики во всей сессии.

Навигация использует URL hash и поддерживает прямые ссылки, перезагрузку, Back/Forward. Неизвестный ID показывает страницу ошибки. Состояние сбрасывается при перезагрузке.

## Границы прототипа

- Только локальные mock data из `lib/mock-data.ts`. Нет backend, авторизации, Prometheus/Actuator, LLM или внешних API.
- Фиксированный снимок: **26 сентября 2026, 14:32 UTC**. Графики синтетические, значения воспроизводимы. Все экраны используют единую временную историю: точки создания совпадают со снимками инцидентов, текущие значения — с Overview. Графики не выходят за время снимка, а исторические закрытые инциденты показывают восстановление. Дельты Golden Signals рассчитываются относительно baseline.
- Инциденты заранее созданы mock-правилами; AI не принимает решения об их создании и не выполняет рекомендации.
- Закрытие инцидента меняет его workflow-статус, но не меняет фиксированный снимок здоровья сервиса. Поэтому Dashboard продолжает показывать `Service is degraded`, даже если все инциденты закрыты вручную.
- Публичная публикация и серверная бизнес-логика не реализованы. Инструменты сборки созданы стандартным Sites scaffold, без хранилищ или подключения облачных сервисов.
